# Changelog

All notable changes to the official STRATAON Zabbix templates are documented in this file.

## [1.8] - 2026-09-11

### Added

- Added support for sentiaLOK.
- Added Product ID `6`.
- Added the `STRATAON sentiaLOK SNMP` template.
- Added monitoring support for up to 32 sentiaLOK subordinate stations.
- Added node, name, communication status, firmware and device type information for each station.
- Added monitoring of 8 digital inputs and 8 digital outputs per station.

### Compatibility

- Based on STRATAON-MIB v1.8.
- Zabbix export format version 7.4.
- Supports the following STRATAON products:
  - miniPLC
  - smartPDU
  - miniENV
  - sentiaMAN
  - sentiaPRO
  - sentiaLOK

## Previous Versions

Earlier template revisions correspond to previous STRATAON MIB releases. Version-specific release information is maintained through the STRATAON GitHub repositories.
