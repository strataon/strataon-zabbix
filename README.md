# STRATAON Zabbix Templates

Official Zabbix monitoring templates for STRATAON devices.

This repository provides official Zabbix templates for monitoring STRATAON products through SNMP.

## Supported Products

The current STRATAON Zabbix templates include support for:

- miniPLC
- smartPDU
- miniENV
- sentiaMAN
- sentiaPRO
- sentiaLOK

Support may vary according to product model and firmware version.

## Requirements

- Zabbix 7.4 or compatible version
- SNMP enabled on the STRATAON device
- Network connectivity between the Zabbix server/proxy and the monitored device
